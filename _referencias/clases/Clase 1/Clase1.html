Aprendiendo HTML desde cero

Guía sencilla para conocer las principales etiquetas HTML

```
```

¿Qué es HTML?

HTML significa HyperText Markup Language.

HTML es el lenguaje que utilizamos para crear la estructura de una página web.

Con HTML podemos indicar que una parte de la página es un título, otra es un párrafo, otra es una imagen, otra es un formulario, etc.

Una página HTML está formada por etiquetas.

Idea fundamental:

HTML define principalmente qué elementos tiene una página.

CSS define cómo se ven esos elementos.

JavaScript define qué comportamiento tienen.

1. <html>

¿Qué es?

Es la etiqueta principal de un documento HTML.

Todo el contenido de una página HTML se encuentra dentro de esta etiqueta.

¿Para qué sirve?

Sirve para indicar al navegador que todo lo que está dentro del elemento corresponde a un documento HTML.

Código

``` 
<html>

    Contenido de la página

</html>
```
Resultado

La etiqueta no genera algo visible por sí misma. Define el comienzo y el final del documento HTML.

2. <head>

¿Qué es?

Es la sección que contiene información sobre la página web.

¿Para qué sirve?

Se utiliza para colocar configuraciones, el título de la página, estilos CSS y otra información que necesita el navegador.

Código

``` 
<head>

    <title>Mi página</title>

</head>
```
Resultado

El contenido de <head> normalmente no aparece directamente en la página.

3. <title>

¿Qué es?

Define el título de la página web.

¿Para qué sirve?

Sirve para definir el texto que aparece en la pestaña del navegador.

``` 
<title>
    Mi primera página
</title>
```
Resultado

Mirá la pestaña del navegador. Allí debería aparecer:

Mi primera página

4. <body>

¿Qué es?

Es el cuerpo de la página HTML.

¿Para qué sirve?

Dentro de <body> colocamos todo aquello que queremos mostrar al usuario.

``` 
<body>

    <h1>Hola mundo</h1>

    <p>Mi primera página web</p>

</body>
```
Resultado

Hola mundo

Mi primera página web

5. <h1> hasta <h6>

¿Qué son?

Son etiquetas que permiten crear títulos y subtítulos.

¿Para qué sirven?

Sirven para organizar jerárquicamente los títulos de una página.

<h1> es el título de mayor importancia y <h6> el de menor nivel.

``` 
<h1>Título principal</h1>

<h2>Subtítulo</h2>

<h3>Título secundario</h3>
```
Resultado

Título principal

Subtítulo

Título secundario

6. <p>

¿Qué es?

<p> significa párrafo.

¿Para qué sirve?

Se utiliza para escribir bloques de texto.

``` 
<p>
    HTML es un lenguaje de marcado.
</p>
```
Resultado

HTML es un lenguaje de marcado.

7. <a>

¿Qué es?

Es la etiqueta utilizada para crear enlaces.

¿Para qué sirve?

Permite que el usuario pueda ir desde una página hacia otra página o recurso.

``` 
<a href="https://www.google.com">
    Ir a Google
</a>
```
Resultado
Ir a Google

El atributo href indica hacia dónde debe dirigirnos el enlace.

8. <img>

¿Qué es?

Es la etiqueta utilizada para mostrar imágenes.

¿Para qué sirve?

Permite incorporar una imagen dentro de una página web.

``` 
<img
    src="https://picsum.photos/300/150"
    alt="Imagen de ejemplo"
>
```
Resultado

src indica dónde está la imagen.

alt contiene una descripción de la imagen.

9. <ul> y <li>

¿Qué son?

<ul> crea una lista sin orden.

<li> representa cada elemento de la lista.

¿Para qué sirven?

Permiten mostrar información mediante una lista de elementos.

``` 
<ul>

    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>

</ul>
```
Resultado
  • HTML
  • CSS
  • JavaScript

10. <ol>

¿Qué es?

Es una lista ordenada.

¿Para qué sirve?

Sirve cuando el orden de los elementos es importante.

``` 
<ol>

    <li>Crear HTML</li>
    <li>Crear CSS</li>
    <li>Agregar JavaScript</li>

</ol>
```
Resultado
  1. Crear HTML
  2. Crear CSS
  3. Agregar JavaScript

11. <div>

¿Qué es?

Es un contenedor genérico.

¿Para qué sirve?

Sirve para agrupar diferentes elementos.

Es muy utilizado para organizar la estructura de una página y aplicar CSS.

``` 
<div>

    <h2>Alumno</h2>

    <p>Nombre: Ana</p>

</div>
```
Resultado

Alumno

Nombre: Ana

12. <form>

¿Qué es?

Es la etiqueta que permite crear formularios.

¿Para qué sirve?

Sirve para permitir que el usuario ingrese información y posteriormente enviarla a un servidor.

``` 
<form>

    <label>Nombre:</label>

    <input type="text">

    <button>Enviar</button>

</form>
```
Resultado

13. <label> ⭐ MUY IMPORTANTE

¿Qué es?

<label> es una etiqueta que identifica o describe un campo de un formulario.

Es el texto que le indica al usuario qué debe ingresar o seleccionar.

¿Para qué sirve?

Sirve para relacionar un texto con un campo del formulario.

Esto hace que el formulario sea más claro y también mejora la accesibilidad.

Código

``` 
<label for="nombre">
    Nombre:
</label>

<input
    type="text"
    id="nombre"
>
```
Resultado

¿Qué significa for="nombre"?

El atributo for del <label> debe coincidir con el id del campo.

Por ejemplo:

for="nombre"

debe coincidir con:

id="nombre"

De esta manera el navegador sabe que el label "Nombre" corresponde al campo.

14. <input>

¿Qué es?

Es uno de los elementos más utilizados en los formularios.

¿Para qué sirve?

Permite que el usuario ingrese o seleccione información.

Su comportamiento depende del atributo type.

Texto

``` 
<input type="text">
```

Email

``` 
<input type="email">
```

Password

``` 
<input type="password">
```

Número

``` 
<input type="number">
```

15. Checkbox

¿Qué es?

Es un campo que permite marcar o desmarcar una opción.

¿Para qué sirve?

Se utiliza cuando el usuario puede elegir una o varias opciones.

``` 
<input
    type="checkbox"
    id="terminos"
>

<label for="terminos">
    Acepto los términos
</label>
```

16. Radio Button

¿Qué es?

Es un tipo de input que permite elegir una sola opción entre varias.

¿Para qué sirve?

Se utiliza cuando el usuario debe seleccionar una única opción.

``` 
<input
    type="radio"
    name="lenguaje"
    id="java"
>

<label for="java">
    Java
</label>

<input
    type="radio"
    name="lenguaje"
    id="python"
>

<label for="python">
    Python
</label>
```

¿Por qué usamos name?

Los radio buttons que tienen el mismo name forman parte del mismo grupo.

Por eso solamente podemos seleccionar uno.

17. <select> y <option>

¿Qué son?

<select> crea una lista desplegable.

<option> representa cada opción disponible.

¿Para qué sirven?

Permiten que el usuario seleccione una opción de una lista.

``` 
<select>

    <option>Java</option>
    <option>Python</option>
    <option>JavaScript</option>

</select>
```

18. <textarea>

¿Qué es?

Es un campo de texto que permite escribir varias líneas.

¿Para qué sirve?

Es útil para comentarios, descripciones, mensajes y textos largos.

``` 
<textarea>
</textarea>
```

19. <button>

¿Qué es?

Es un elemento que representa un botón.

¿Para qué sirve?

Permite que el usuario realice una acción, por ejemplo enviar un formulario o ejecutar una función JavaScript.

``` 
<button>
    Hacer clic
</button>
```

En este ejemplo agregamos onclick para mostrar que el botón puede ejecutar una acción.

20. <table>, <tr>, <th> y <td>

¿Qué son?

Son etiquetas utilizadas para construir tablas.

¿Para qué sirven?

Permiten organizar información en filas y columnas.

``` 
<table>

    <tr>

        <th>Nombre</th>
        <th>Edad</th>

    </tr>

    <tr>

        <td>Ana</td>
        <td>22</td>

    </tr>

</table>
```
Nombre Edad
Ana 22
Juan 25

<table> → crea la tabla.

<tr> → crea una fila.

<th> → crea un encabezado.

<td> → contiene un dato.

21. Etiquetas semánticas

¿Qué significa "semántica"?

Significa que la etiqueta nos ayuda a entender qué representa el contenido.

¿Para qué sirven?

Permiten organizar mejor la estructura de una página y facilitan que los navegadores, buscadores y tecnologías de asistencia entiendan el contenido.

``` 
<header>

    Encabezado

</header>

<nav>

    Menú

</nav>

<main>

    Contenido principal

    <section>

        Una sección

    </section>

</main>

<footer>

    Pie de página

</footer>
```
Estructura conceptual
HEADER
NAV
MAIN
SECTION
FOOTER

<header> → encabezado.

<nav> → navegación.

<main> → contenido principal.

<section> → sección de contenido.

<footer> → pie de página.
