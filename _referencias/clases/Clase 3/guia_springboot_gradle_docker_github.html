Crear un proyecto Spring Boot desde cero

Java + Spring Boot + Gradle + MySQL en Docker + GitHub

🎯 Objetivo de la clase

En esta guía vamos a crear una aplicación backend utilizando Java y Spring Boot, administrando las dependencias con Gradle y utilizando MySQL dentro de Docker como base de datos.

Al finalizar tendremos:

  • Un proyecto Spring Boot funcionando.
  • Un proyecto Java administrado con Gradle.
  • Una base de datos MySQL ejecutándose en un contenedor Docker.
  • Una API REST para consultar y guardar alumnos.
  • El código versionado y publicado en GitHub.

6Crear la base de datos con Docker

En lugar de instalar MySQL directamente en nuestra computadora, vamos a ejecutarlo dentro de un contenedor.

En la raíz del proyecto creá: 

compose.yaml

Colocá:

services:
  mysql:
    image: mysql:8.4
    container_name: alumnos-mysql
    environment:
      MYSQL_DATABASE: alumnosdb
      MYSQL_USER: alumno
      MYSQL_PASSWORD: alumno123
      MYSQL_ROOT_PASSWORD: root123
    ports:
      - "3306:3306"
    volumes:
      - mysql_data:/var/lib/mysql

volumes:
  mysql_data:

Desde la carpeta del proyecto ejecutá:

docker compose up -d

Comprobá que el contenedor esté ejecutándose:

docker ps
Si aparece alumnos-mysql con estado Up, MySQL está funcionando dentro del contenedor.

8Crear nuestra primera entidad

Vamos a representar un alumno mediante una clase Java.

Creá:

src/main/java/com/example/alumnosapi/model/Alumno.java
package com.example.alumnosapi.model;

import jakarta.persistence.Entity;
import jakarta.persistence.GeneratedValue;
import jakarta.persistence.GenerationType;
import jakarta.persistence.Id;

@Entity
public class Alumno {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    private String nombre;
    private String email;

    public Alumno() {
    }

    public Alumno(String nombre, String email) {
        this.nombre = nombre;
        this.email = email;
    }

    public Long getId() {
        return id;
    }

    public String getNombre() {
        return nombre;
    }

    public void setNombre(String nombre) {
        this.nombre = nombre;
    }

    public String getEmail() {
        return email;
    }

    public void setEmail(String email) {
        this.email = email;
    }
}

¿Qué estamos haciendo?

  • @Entity indica que la clase será persistida.
  • @Id identifica la clave primaria.
  • @GeneratedValue permite generar el ID automáticamente.

9Crear el Repository

Creá:

repository/AlumnoRepository.java
package com.example.alumnosapi.repository;

import com.example.alumnosapi.model.Alumno;
import org.springframework.data.jpa.repository.JpaRepository;

public interface AlumnoRepository
        extends JpaRepository<Alumno, Long> {
}

Spring Data JPA nos permite trabajar con la entidad utilizando operaciones de persistencia sin tener que escribir manualmente todas las consultas básicas.

10Crear nuestro Controller

Creá:

controller/AlumnoController.java
package com.example.alumnosapi.controller;

import com.example.alumnosapi.model.Alumno;
import com.example.alumnosapi.repository.AlumnoRepository;
import org.springframework.web.bind.annotation.*;

import java.util.List;

@RestController
@RequestMapping("/api/alumnos")
public class AlumnoController {

    private final AlumnoRepository repository;

    public AlumnoController(AlumnoRepository repository) {
        this.repository = repository;
    }

    @GetMapping
    public List<Alumno> obtenerTodos() {
        return repository.findAll();
    }

    @PostMapping
    public Alumno crear(@RequestBody Alumno alumno) {
        return repository.save(alumno);
    }
}

Ahora tenemos dos operaciones:

Método Endpoint Acción
GET /api/alumnos Obtener alumnos
POST /api/alumnos Crear alumno

Cuando realizamos un POST:

  1. El cliente envía una petición HTTP.
  2. Spring recibe la petición en el Controller.
  3. @RequestBody transforma el JSON en un objeto Java.
  4. El Controller utiliza el Repository.
  5. JPA realiza la operación contra MySQL.
  6. La base de datos almacena el registro.
  7. Spring devuelve una respuesta HTTP.

  • Cómo se conecta Spring Boot con MySQL.
  • Qué hace @Entity.
  • Qué hace @RestController.
  • Qué función cumple el Repository.
  • Qué diferencia hay entre GET, POST y DELETE.
  • Qué ocurre cuando llega una petición al Controller.
