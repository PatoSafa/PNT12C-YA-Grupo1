1. Repaso: ¿qué es HTML?

HTML significa HyperText Markup Language. Se utiliza para definir la estructura y el contenido de una página web.

Estructura mínima

<!DOCTYPE html> <html lang="es"> <head> <meta charset="UTF-8"> <title>Mi página</title> </head> <body> <h1>Hola mundo</h1> <p>Esta es mi primera página.</p> </body> </html>
Idea clave: HTML no se ocupa principalmente de "hacer bonito" el sitio. HTML organiza qué contenido existe y qué significado tiene.

Etiquetas que ya conocemos

  • <h1> → título principal.
  • <h2> → subtítulo.
  • <p> → párrafo.
  • <ul> y <li> → lista.
  • <a> → enlace.
  • <img> → imagen.
  • <form> → formulario.

2. Agregamos una imagen

Para mostrar una imagen utilizamos <img>. Es una etiqueta que no necesita una etiqueta de cierre.

Paso 1: indicar dónde está la imagen

<img src="imagenes/computadora.jpg" alt="Computadora">

Paso 2: comprender los atributos

  • src: indica la ubicación de la imagen.
  • alt: describe la imagen.

3. Tema nuevo: CSS

CSS significa Cascading Style Sheets. Se utiliza para definir la presentación visual de una página HTML.

La idea fundamental

HTML → estructura

CSS → apariencia

JavaScript → comportamiento e interacción

Forma 1: CSS en línea

Se escribe directamente dentro del elemento:

<p style="color: blue;"> Hola </p>

Este párrafo es un ejemplo de CSS en línea.

Es sencillo para probar algo puntual, pero no es la opción más conveniente cuando tenemos muchos elementos.

Forma 2: CSS interno

Se coloca dentro de <style>, generalmente dentro de <head>.

<style> p { color: green; } </style>

Forma 3: CSS externo ⭐

Creamos un archivo separado, por ejemplo: estilos.css.

En el HTML lo conectamos mediante:

<link rel="stylesheet" href="estilos.css">

Y dentro de estilos.css escribimos:

p { color: green; font-size: 18px; } h1 { text-align: center; }
Concepto importante: HTML y CSS pueden estar en archivos diferentes. El HTML contiene la estructura y el CSS define la apariencia.

¿Cómo funciona una regla CSS?

p { color: red; font-size: 20px; }
  • p → selector.
  • color → propiedad.
  • red → valor.
  • font-size → otra propiedad.
  • 20px → valor.

4. Tema nuevo: JavaScript

JavaScript permite agregar comportamiento e interacción a una página.

Paso 1: crear una función

function saludar() { alert("¡Hola!"); }

Paso 2: conectar la función con un botón

<button onclick="saludar()"> Saludar </button>

Paso 3: modificar contenido HTML

Este texto puede ser modificado por JavaScript.

function cambiarTexto() { document.getElementById("mensaje").textContent = "¡El texto cambió utilizando JavaScript!"; }

Paso 4: conectar un archivo JavaScript externo

Al igual que CSS, JavaScript puede estar en un archivo separado.

<script src="script.js"></script>

Y en script.js podríamos tener:

function cambiarTexto() { document.getElementById("mensaje").textContent = "Texto modificado."; }
Idea clave: HTML crea los elementos, CSS los presenta y JavaScript puede hacer que respondan a las acciones del usuario.

5. HTML + CSS + JavaScript juntos

HTML ↓ ¿Qué elementos existen? ↓ CSS ↓ ¿Cómo se ven? ↓ JavaScript ↓ ¿Qué hacen cuando ocurre algo?

Ejemplo conceptual

<button id="boton">Cambiar</button> <script> document.getElementById("boton").onclick = function() { document.body.style.backgroundColor = "lightblue"; }; </script>

6. Actividad práctica

Parte A — HTML

  1. Crear una página llamada index.html.
  2. Agregar un título principal.
  3. Agregar dos párrafos.
  4. Agregar una lista de tres elementos.
  5. Agregar una imagen con src y alt.

Parte B — CSS

  1. Crear una carpeta llamada css.
  2. Crear dentro un archivo estilos.css.
  3. Conectar el CSS desde el HTML usando <link>.
  4. Cambiar el color del título.
  5. Cambiar el tamaño de los párrafos.
  6. Agregar un color de fondo.

Parte C — JavaScript

  1. Crear una carpeta llamada js.
  2. Crear un archivo script.js.
  3. Conectarlo con el HTML usando <script>.
  4. Crear un botón.
  5. Hacer que al presionarlo cambie un texto.
Desafío: Agregá un segundo botón que cambie el color de fondo de la página. No copies todo el código nuevamente: modificá tu propia solución.
