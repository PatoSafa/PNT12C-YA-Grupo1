Guía: Login con AJAX → Home → listado con AJAX

Objetivo: construir un login que se comunique con Spring Boot mediante AJAX y, si las credenciales son correctas, redirigir a home.html. En Home se muestran los datos del usuario y se consulta mediante AJAX el endpoint GET /api/elemento.

Login → POST /login → OK → guardar usuario → /home.html → GET /api/elemento → llenar tabla

1. Preparar el Home

Crear:

src/main/resources/static/home.html

El archivo tendrá una sección para los datos del usuario y una tabla para los elementos.

<div class="usuario">
    <p>Email: <span id="usuarioEmail"></span></p>
    <p>Nombre: <span id="usuarioNombre"></span></p>
</div>

<table>
    <thead>
        <tr>
            <th>ID</th>
            <th>Nombre</th>
        </tr>
    </thead>
    <tbody id="tablaBody"></tbody>
</table>

2. Incorporar jQuery

<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>

Esto permite utilizar $.ajax() para realizar llamadas HTTP desde JavaScript.

3. Recibir los datos del usuario

En este ejemplo se utiliza sessionStorage para pasar temporalmente los datos desde el login al Home.

El login debe guardar un objeto JSON:

sessionStorage.setItem("usuario", JSON.stringify(response.usuario));
window.location.href = "/home.html";

Por ejemplo, si el backend devuelve:

{
    "mensaje": "Login correcto",
    "usuario": {
        "email": "ana@mail.com",
        "nombre": "Ana"
    }
}

4. Recuperar el usuario en Home

const usuario = JSON.parse(sessionStorage.getItem("usuario"));

if (usuario) {
    $("#usuarioEmail").text(usuario.email);
    $("#usuarioNombre").text(usuario.nombre);
}

Importante: esto sirve para el ejercicio de AJAX. En una aplicación real, la autenticación no debería basarse solamente en datos almacenados en el navegador.

5. Crear el AJAX GET

Cuando Home carga, JavaScript realiza:

$.ajax({
    url: "/api/elemento",
    type: "GET",
    success: function(elementos) {
        // procesar respuesta
    },
    error: function() {
        // mostrar error
    }
});

6. Recorrer la respuesta

Suponiendo que el backend devuelve un listado como:

[
    { "id": 1, "nombre": "Elemento 1" },
    { "id": 2, "nombre": "Elemento 2" },
    { "id": 3, "nombre": "Elemento 3" }
]

Se puede recorrer con forEach:

elementos.forEach(function(elemento) {
    const fila = `
        <tr>
            <td>${elemento.id}</td>
            <td>${elemento.nombre}</td>
        </tr>`;

    $("#tablaBody").append(fila);
});

7. Backend para GET /api/elemento

El controlador debe exponer un endpoint GET. Por ejemplo:

@GetMapping("/api/elemento")
@ResponseBody
public List<Elemento> listar() {
    return service.listar();
}

El endpoint debe devolver JSON para que JavaScript pueda recorrer la respuesta.

8. Redirección después del login

Como el login es AJAX, no se utiliza directamente:

return "redirect:/home";

La respuesta OK vuelve a JavaScript y JavaScript realiza la navegación:

success: function(response) {
    sessionStorage.setItem("usuario", JSON.stringify(response.usuario));
    window.location.href = "/home.html";
}

9. Ejemplo completo del AJAX del login

$("#loginForm").submit(function(event) {
    event.preventDefault();

    const login = {
        email: $("#email").val(),
        clave: $("#clave").val()
    };

    $.ajax({
        url: "/login",
        type: "POST",
        contentType: "application/json",
        data: JSON.stringify(login),

        success: function(response) {
            sessionStorage.setItem(
                "usuario",
                JSON.stringify(response.usuario)
            );

            window.location.href = "/home.html";
        },

        error: function(xhr) {
            $("#mensaje").text(xhr.responseText);
        }
    });
});

10. ¿Qué ocurre cuando todo funciona?

  1. El alumno completa email y clave.
  2. JavaScript intercepta el submit.
  3. AJAX hace POST /login.
  4. Spring Boot recibe el JSON.
  5. El service verifica las credenciales.
  6. Si son correctas, el backend devuelve HTTP 200 y los datos del usuario.
  7. JavaScript guarda temporalmente el usuario en sessionStorage.
  8. JavaScript navega a /home.html.
  9. Home recupera los datos del usuario y los muestra.
  10. Home ejecuta un GET /api/elemento.
  11. Spring Boot devuelve el listado en JSON.
  12. JavaScript recorre el listado y genera las filas de la tabla.
Para probarlo con Postman: primero probar POST /login y comprobar que devuelve HTTP 200 y el usuario. Después probar GET /api/elemento y verificar que devuelve un array JSON de elementos.
