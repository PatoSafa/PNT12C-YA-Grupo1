1. Variables + input + alert()

Idea: JavaScript puede obtener información escrita por el usuario, guardarla en una variable y utilizarla.

Código JavaScript

function saludar() { const nombre = document.getElementById("nombreDemo").value; if (nombre === "") { alert("Ingresá tu nombre"); return; } alert(`Hola ${nombre}!`); }

Probalo


¿Qué sucede?
  1. getElementById() busca el elemento HTML.
  2. .value obtiene lo que escribió el usuario.
  3. El valor se guarda en nombre.
  4. if verifica si está vacío.
  5. alert() muestra una ventana.

2. Funciones + eventos + DOM

Idea: una función contiene instrucciones que podemos ejecutar varias veces. En este ejemplo modificamos el contenido de un elemento HTML.

Código JavaScript

let contador = 0; function incrementar() { contador++; actualizarContador(); } function decrementar() { contador--; actualizarContador(); } function actualizarContador() { document.getElementById("contador") .textContent = contador; }

Probalo

0
Conceptos:
  • let permite declarar una variable cuyo valor puede cambiar.
  • contador++ aumenta el valor en uno.
  • textContent modifica el texto del HTML.
  • onclick ejecuta una función cuando hacemos click.

3. Condicionales

Idea: los condicionales permiten que el programa tome decisiones.

Código JavaScript

function verificarEdad() { const edad = Number(document.getElementById("edadDemo").value); if (edad === 0 || isNaN(edad)) { alert("Ingresá una edad válida."); } else if (edad >= 18) { alert("Sos mayor de edad."); } else { alert("Sos menor de edad."); } }

4. Formulario + validaciones

Idea: antes de procesar información podemos verificar que los datos sean correctos.

Código JavaScript

formulario.addEventListener("submit", function(event) { event.preventDefault(); let valido = true; if (nombre.value.trim() === "") { errorNombre.textContent = "El nombre es obligatorio."; valido = false; } if (edad.value === "") { errorEdad.textContent = "La edad es obligatoria."; valido = false; } if (valido) { alert("Formulario válido."); } else { alert("Hay errores."); } });

5. Validación en tiempo real

Idea: podemos ejecutar JavaScript mientras el usuario escribe. Para esto utilizamos el evento input.

Código JavaScript

const campo = document.getElementById("nombreTiempoReal"); campo.addEventListener("input", function() { const texto = campo.value.trim(); if (texto.length < 3) { mensaje.textContent = "Debe tener al menos 3 caracteres."; } else { mensaje.textContent = "✓ Nombre válido."; } });

Probalo

6. console.log()

Idea: console.log() sirve para mostrar información en la consola del navegador. Es una herramienta fundamental para encontrar errores y entender qué está haciendo nuestro programa.

Código JavaScript

function mostrarEnConsola() { const nombre = "Ana"; const edad = 25; console.log("Nombre:", nombre); console.log("Edad:", edad); console.log("El programa se está ejecutando"); }

Probalo

Presioná el botón y luego abrí F12 → Console.

7. Desafío para los alumnos

  4. Hacé que el nombre tenga como mínimo 5 caracteres.
  5. Agregá una validación para que el email termine en .com.
  6. Agregá un nuevo campo al formulario.
  7. Mostrá los datos ingresados en la página usando innerHTML.
